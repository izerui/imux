## 1. 每一镜看得懂吗？字够不够大？

**1-1　0.0–1.0　开头第一行字太小，第一秒看不出是什么产品**
- 看到的：第一帧只有一行很小的「今天想通了一个道理：」（1080p 下字高约 30px），加上一堆小卡片。卡片标题是「claude · 路径大小写」这类约 12px 的字，完全读不出。
- 问题：手机竖屏刷到时，这行字基本是一条灰线。观众前 1 秒拿不到任何信息。
- 建议：第一屏直接上大字主句（「有些活，不必一个人干」），把「今天想通了一个道理」删掉或者降为 0.3 秒的引子。卡片至少放大到能看出是终端窗口。

**1-2　4.8–12.0　「七个终端」和画面数量对不上**
- 看到的：面板里 Claude Code 5 条 + 「显示更多」，Codex 3 条，Pi 折叠，飞进去的卡片也不是 7 张。
- 问题：较真的开发者会去数。另外，面板里转圈（运行中）、蓝点加粗（未读）这两个 README 重点讲的状态，画面上有，但没有任何提示，观众意识不到。
- 建议：标题改成不带具体数的说法（「一堆终端，收进一个面板」），或者真的只飞 7 张。面板落定后，用手写箭头圈一下转圈和未读圆点，0.5 秒就够。

**1-3　20.2–21.7　「IDE 真本事」的高潮没看清就切了**
- 看到的：21.25 才出现「命中断点 · count = 11 · limit = 10 · 时间窗过期后没有清零」，21.7 就硬切到下一镜，只停了约 0.45 秒。同时镜头推得太近，左边被裁掉（「登录接口限流」只剩「接口限流」，「idea · rename_refactoring」只剩「a · rename_…」，「accept」只剩「cept」）。
- 问题：这一镜是整片唯一讲 IDE 能力的地方，也是 README 第一卖点。现在观众只看清了「sed 被划掉」，「调试器帮你找到 bug」这层意思完全没传达。
- 建议：断点那行至少停 1.5 秒，用手写圈把「时间窗过期后没有清零」圈出来。推镜要停在整行可见的位置，不要裁掉行首。

**1-4　15.0–16.9　标题出画后，最后两秒失去语境**
- 看到的：推近对话框之后，「动手之前，先聊清楚」被推出画面，后两秒只剩一个选项列表。右下角按钮「看一眼」也被画框裁掉一半。
- 问题：这项功能的要点是「问完整理成方案，点 发给 Agent 开始执行」，片中没有这个结果，只停在答题中途，看起来像一个普通问卷。
- 建议：结尾补一拍「发给 Agent」，按钮按下后对话框收起，终端开始跑。推近时标题跟着留在画内，或者换成角标。

**1-5　45.8–50.7　「直接说」四张卡，副标签读不完**
- 看到的：每张 1.2 秒，主句 6–10 个字，下面还有一个约 30px 的状态条（「已开启结对编程 · 副驾驶 Codex」「已预约审查（Codex）：本轮结束后开始」等）。
- 问题：主句勉强能读完，状态条基本来不及读，而状态条才是「说了就生效」的证据。
- 建议：四张减到两张（「开启结对编程」「把截图发我手机」）。每张 1.8–2 秒，状态条放大并加一个「啪」地弹出的动作。

**1-6　41.0–41.6　手机先空着出现**
- 看到的：手机甩进画面时是一个纯黑圆角矩形，0.6 秒后才出现消息。手机比例接近 4:5，更像平板。
- 建议：手机进画时就带着第一条消息；比例改回 9:19.5 左右，加刘海或者状态栏，一眼就认得出是手机。

## 2. 字被遮、被裁、和界面撞车

装饰用的小终端卡片反复压在标题字上。单看每次都不长，但前后出现了七八次，观众会觉得是穿帮。

| 时间 | 情况 |
| --- | --- |
| 0.5–3.5 | 卡片群压在「有些活，不必一个人干」的「一个人干」上 |
| 12.0–14.25 | 卡片压在「动手之前」的「前」上 |
| 17.2–18.75 | 一张卡片正好盖住「让 AI 用上 IDE 的真本事」里的「IDE」；这时标题本身只有约 30% 不透明度，关键词等于消失了 |
| 22.75–27.0 | 小卡片在「一个写，一个挑刺」中间来回穿 |
| 34.0–35.0 | 卡片盖住「捋成一条线」的「捋」 |
| 46.25–46.75 | 卡片压住「「开启结对编程」」的左引号 |
| 47.4–49.4 | 卡片叠在「codex」「审查」字上 |

裁切问题：
- 20.2–21.7：终端左侧被裁，行首丢字（见 1-3）。
- 15.0–16.9：「看一眼」按钮被右边框裁掉。
- 25.25–28.8：右上角的「审查中」按钮组被推出画面顶部，只剩一条边。结对编程的入口按钮本来是值得给一眼的。
- 37.5–38.9：轨迹卡最上面一行被画面顶部裁掉半行。

对比度问题：21.8–28.8「一个挑刺」用的是棕橙色，压在橙色底上，对比度明显不够，而且和前半句「一个写，」的深色不统一，像是还没淡入完。

建议：给标题区设一块禁飞区，装饰卡片的飞行路径一律绕开标题包围盒。推镜终点以「完整一行可见」为准。「一个挑刺」改成深色，或者描一圈浅色边。

## 3. 节奏

**3-1　50.7–53.1　空镜 2.4 秒，最拖的一段**
- 看到的：「把截图发我手机」之后切到一张没有任何元素的夜景城市，只有风线在动，2.4 秒后 logo 才淡入。
- 问题：刚刚还是 1.2 秒一切的快节奏，紧接着一段什么都没有的空镜，节奏一下子塌了。观众很可能以为片子已经结束，直接划走。
- 建议：砍到 0.8 秒以内，或者直接让 logo 从最后一张卡片里长出来。

**3-2　53.2–60.5　品牌卡静止 7 秒**
- 看到的：logo 和标语 53.3 秒就位，55.5 秒加一行 Marketplace 提示，之后到 60 秒画面不再变化。
- 建议：品牌卡 3–3.5 秒足够。如果想要余韵，就让城市窗户逐个亮起、纸飞机飞回来之类，总之画面里得有事情在发生。

**3-3　21.8–33.7　结对和审查连着讲两镜，共 12 秒，中段偏平**
- 看到的：结对一镜 7 秒，Codex 意见 25.5 秒才出，之后 3 秒画面静止。接着「说一句就预约审查」又是同一个终端、同一个橙底，再讲 5 秒。到 48.3 秒「做完让副驾驶审查一次」第三次出现。
- 建议：两镜合成一镜，控制在 6–7 秒，删掉 48.3 秒那张重复卡。省出来的时间还给 IDE 能力（1-3）和先聊再做的结果（1-4）。

**3-4　转场**
- 16.9 和 21.7 是硬切，而且切点都落在「刚出关键信息」的时刻（见 1-3）。其他转场都是「卡片群扫过」或者推进窗户这类有设计的过渡，这两处显得是被截断的。
- 12.0 和 28.9 的卡片扫屏转场还不错，但两次用的是同一个动作，第二次已经没有新鲜感。
- 39.0–41.0 推进窗户、飞纸飞机这段桥接，意思是「人离开」，想法是好的。但 41.0 切到海边是硬切，色调从深绿夜景直接跳到橙色日落，跳得有点猛。可以让纸飞机飞出画面后直接从海边那一侧落下来，用它串起两镜。

**3-5　音轨**
- 整体响度 -14.1 LUFS、真峰值 -0.3 dBTP、LRA 2.5 LU，作为短视频平台投放是合格的。只是峰值贴得太近，平台重新编码后可能削波，建议压到 -1 dBTP。
- **开头没有淡入**：第一个 50ms 采样峰值就到了约 -10 dBFS，音乐像是从一首歌中间直接切进来。建议 0.2–0.3 秒淡入，或者从一个明确的起拍开始。
- **结尾音乐被硬切**：59.07 秒从约 -13 dB 一下掉到数字静音，这时画面还在品牌卡上，没有任何淡出。
- **60.1–60.5 有一段约 -30 dB 的残响又冒出来**，紧跟在 1 秒静音之后，听感上像一个小噗声，是明显的瑕疵。建议音乐在品牌卡最后 1.5 秒内做淡出，结束点和画面淡黑对齐，片尾那段残留剪掉。
- 41.3–42.9 音乐有一段约 -26 dB 的空拍，刚好落在「人走开了」上，这一处是加分的，保留。

## 4. 翻页 PPT 感、AI 味

- **4.8–38.9 这 34 秒几乎全是「橙色径向渐变底 + 几条白色弧线 + 一个深色窗口截图 + 左上角手写标题」**，唯一的运镜是慢推慢移。六个功能换来换去都是这一套模板，这是全片 PPT 感最重的部分。参考片每一镜的场景、构图、景别都不一样，这里只是在换截图。
- **45.8–50.7 的「不用点菜单，直接说」**：纯色底、居中大字、下方一个胶囊标签，橙绿交替翻四页，几乎就是一组幻灯片。
- **AI 味**：
  - 「今天想通了一个道理：」是很套路的鸡汤开头。
  - 背景上那些半透明白色「风线」从头飘到尾，每一镜都有，又不服务任何内容，像是生成模板自带的装饰。
  - 装饰卡片一直在飘，但它们不和任何东西发生关系（不被点开，也不落进什么地方），只是在填空。
- 建议：给中段每个功能一个和夜景同一套插画语言的小场景，同时保留真实 UI。比如先聊再做可以是一张窗边的书桌，轨迹可以是一根毛线被捋直（33.8–35.9 这里已经有这个苗头，做得最好）。装饰卡片要么承担叙事（飞进面板、落进手机），要么删掉。

## 5. 画风不统一

全片至少混了三套视觉语言：

1. **撕纸质感的夜景城市**（0–4.7、39–41、50.7–60.5）：有纸边、有手绘不规整，和「治愈系插画」的方向一致，是全片最有风格的部分。
2. **橙色渐变 + 拟物 macOS 截图**（4.8–38.9、45.8–50.7）：干净的 UI 截图加软阴影，是 SaaS 产品片的常见做法，和第 1 套之间没有任何视觉上的过渡，看起来像从另一支片子里接过来的。
3. **矢量日落海面 + 灯塔**（41.0–45.8）：平涂矢量，没有纸纹，和第 1 套夜景城市的撕纸笔触明显不是一个画师。

另外，手写字体只用在大标题上，UI 部分全是系统字，这本身没问题。但 28.9–33.7 的「说一句，就预约审查」突然用了米色便签纸贴片，全片只此一处，显得很突兀。

建议：把撕纸夜景这套定为主风格。中段的橙底换成同一套纸纹（比如暖色台灯下的纸面桌面），截图边缘加一点纸边或者胶带。海边那镜补上纸纹和不规整轮廓。便签贴纸要么在每一镜都用，要么去掉。

## 6. 开头 3 秒和结尾

- **开头 3 秒抓不住人**：画面是安静的夜景，飞进来一群看不清的小卡片，唯一的大字「有些活，不必一个人干」到 1.0–1.5 秒才打完，还被卡片压着。3 秒内观众不知道这是编程工具，也没有任何反差或者疑问能把人留住。
  - 建议：0–1 秒先给一个痛点画面（满屏终端窗口乱糟糟叠在一起，配一句「七个终端，哪个跑完了？」），1–3 秒用一个动作把它们一把收进面板。可以直接把现在 4.8–8.5 那段「卡片飞进面板」提到开头当钩子，它是全片最有爽感的一个动作。
- **结尾落在品牌上**，logo、标语、Marketplace 搜索提示都有，这一点合格。问题是前面有 2.4 秒空镜，品牌卡本身静止 7 秒，音乐又提前 1.5 秒硬断（见 3-1、3-2、3-5）。
  - 建议：品牌卡提前 2 秒出现。「JetBrains Marketplace 搜索 imux」这一行字太小（约 28px），应该放大到和标语同一级，因为它是唯一的行动指引。

## 最该改的三条（按重要程度排序）

1. **中段 34 秒是「橙底 + 截图」翻页，和夜景插画是两支片子。** 4.8–38.9 加上 45.8–50.7 都是同一套橙色渐变模板换截图，和片头片尾的撕纸夜景、41 秒的矢量海景画风完全不统一，这是「PPT 感」和「像拼起来的」的根源。改法：把撕纸插画定为主风格，中段每个功能给一个同一套插画语言的小场景（台灯纸桌面、毛线捋直等），真实 UI 放进场景里，不要直接贴在渐变底上。「直接说」四张翻页卡砍掉一半，并融进场景里。
2. **最关键的信息没给够时间，还被遮、被裁。** 20.2–21.7 断点结论只停 0.45 秒、行首被裁，这是 README 第一卖点；17.2–18.75 卡片盖住标题里的「IDE」；装饰卡片前后七八次压字；15–17 和 25–29 关键按钮被推出画外。改法：标题区设禁飞区，推镜终点保证整行可见，每个功能的「结果那一下」至少停 1.5 秒并用手写圈标出。省时间的办法是把结对和审查的三次重复（21.8–33.7、48.3–49.4）合并成一镜。
3. **开头不抓人，结尾拖且音频硬断。** 0–3 秒是安静夜景加小字鸡汤，看不出这是编程工具；50.7–53.1 空镜 2.4 秒，品牌卡静止 7 秒；音乐开头没有淡入，59.07 秒硬切到静音，60.1 秒还冒出一段残响。改法：把「卡片飞进面板」提到开头做钩子；空镜压到 0.8 秒以内，品牌卡压到约 3.5 秒，Marketplace 搜索提示放大；音乐首尾做淡入淡出，和画面淡黑对齐，剪掉片尾残响，真峰值压到 -1 dBTP。
