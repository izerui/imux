# imux 任务交互原型

这是一次性 HTML 交互探索，不是插件实现。不连接模型、不启动 CLI、不执行命令、不修改工程；任务、改动和测试结果均为模拟。输入框只记录输入，不理解自然语言。

## 打开

直接打开 `design-demos/index.html`，无需网络或安装依赖。三个独立入口为 `session.html`、`task.html`、`team.html`，共用 CSS 和 JavaScript。

也可在此目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory design-demos
```

## 三个初稿方向，等待选择

- A：会话为主，深色 IDE，默认收起详情。当前会话关联任务，不新增会话。
- B：任务与会话并列，浅色 IDE，默认展示详情。新任务创建会话，可交接给其他执行者。
- C：显式批准委派，深绿灰详情区，展示主会话及隔离子任务。不是默认自动分发。

每次演示只保留一项任务，刷新重置。功能包括：关联、新建、任务/会话切换、模拟推进、确认/拒绝、失败重试、交接、关闭恢复、停止、委派审批、示例差异、验收。没有手机交互原型、预约或记忆界面。

## 已做验证

- `node --check design-demos/prototype.js` 通过。
- 浏览器点击：当前会话关联→修改→确认→验证→设备验收，走通。
- 浏览器点击：新建→创建会话→交接 Pi，负责人更新且状态停止等待继续。
- 浏览器点击：批准委派→停止→继续→关闭→恢复，恢复后等待主动继续。
- 三个方向截图已保存。人工查看 C 的截图；A/B 截图尚未逐张视觉审查，375px 未实测。

## 交付范围

仅新增本目录，不改插件。侧栏与会话入口为模拟；三个 CLI 只是选项，不证明实际支持。真实 MCP、手机、跨平台执行、语言资源、平台 API、宣传视频与生产状态机制均不涉及修改。未运行 Gradle，不应将浏览器模拟通过当成插件功能通过。
