# 手机助手入口原型 v2

入口：design-demos/bot.html；CSS/JS 同目录，无远程依赖。

## 设计假设
沿用上一轮 IDE 语境，新增手机与控制中心联动，不改真实插件。暂按本机独立控制中心演示，部署选择未获得用户确认。三个工程均是示例；所有执行与验证均模拟。

手机连接助手，不必绑定会话；消息选工程后创建任务；任务通过执行关联会话。显式批准委派；交接改变会话但任务关注不变。未开工程可以明确启动或只存待办。控制中心不可用不接收，不伪造机器人回复。会话直连是单独模式。普通“允许”不作为授权。

## 打磨记录
- 首轮补齐手机上的委派、交接、待办启动、失败恢复与验收入口，避免只能在电脑操作。
- 修复任务列表手机按钮被末尾 render 覆盖的问题。
- 390px 全页截图检查：手机与控制中心纵向堆叠，无横向裁切；桌面截图已生成。
- 原型只支持有限预设动作；自由文本默认发起新需求，非真正自然语言理解。

## 验证
Node 语法检查通过。浏览器已点通未绑定→需求→工程→任务/会话创建→委派→指定确认→结果→验收；工程关闭→保存待办；两项任务列表；控制中心不可用→拒收输入。交接和直连按钮已实现，但本轮未逐步回归；真实配对、文件发送、进程、费用管理均未实现。

## 边界
环境切换是演示控制：将活跃任务置为停止以防模拟误继续，不等同真实失联状态机。真实设计需要“未知/待核对”，不能将失联等同已停止。任务创建是模拟立即完成，未演示启动中、创建失败与重启恢复。

只新增本原型，未改 Kotlin、MCP、机器人连接、CLI 适配。三个 CLI 仅为模拟执行名称；跨平台、语言资源、宣传片、平台验证本轮不涉及。前端为中文，非插件多语言交付。未运行 Gradle。
