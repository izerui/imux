# 会话信息与能力：方向评审

日期：2026-11-04。状态：三方向初稿，未选择实施方案。

受众：在 imux 中使用 Claude Code、Codex、Pi 的开发者。
场景：写代码时确认当前会话拿到了哪些能力，以及信息来自哪里。
输出：三个离线可打开的单文件 HTML，桌面 1440×900、移动浏览 375×812。
主题：沿用项目已有 JetBrains 明暗主题。深色不是装饰性品牌选择，而是原产品上下文。

共同内容：会话身份、MCP 配置、技能、规则或插件、运行信息、数据来源。
三种智能体分别显示已确认可获得的信息，不强求完全相同的字段。
所有交互数据均为示例；不连接用户正在运行的 CLI，不读取凭据。
刷新只改变示例查询时间，不能把配置推断成连接成功。
不把技能被发现说成正文已进入上下文，不把规则加载说成模型已遵守。

Form 五问：
- 叙事角色：正在工作时的检查工具，不是产品介绍。
- 观众距离：近距离、高频扫描。
- 视觉温度：克制，与 IDE 一致。
- 容量：先给来源和状态，展开后给路径和说明。
- 视觉母题：终端会话、工具清单、原生列表。

验收：三个布局均可切换智能体、搜索、查看分类、查看条目来源、关闭与重新打开。
移动端只保证评审可读，不暗示 JetBrains 插件支持手机运行。
