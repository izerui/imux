“添加机器人”三页的布局方向

现在的问题：扫码页说明用固定宽度的 HTML 换行，标签比文字宽出一截，整块内容偏左；选渠道页、扫码页、配对页各自对齐，翻页时内容位置来回跳。 三个方向都只用 Swing 现有控件，内容区 560×360 不变，区别在“对齐的那根轴”放在哪里。

方向 A　居中的固定栏

三页共用一根 420px 宽、水平居中、顶部对齐的内容栏，栏内文字左对齐（IntelliJ 向导的写法）。标题始终在同一高度，翻页时只有栏内内容换，位置不跳。扫码页二维码和说明在栏内左右排，整体居中。

方向 B　一根中轴

参照微信、飞书桌面端扫码登录：所有内容沿垂直中轴居中堆叠。选渠道是一排四个等宽卡片；扫码页二维码在上、说明在下；配对码居中放大。最直观，“居中”最彻底，但说明要短，长提示会换成多行。

方向 C　左列表 + 右内容（合并前两页）

参照 IntelliJ 设置页：左边固定渠道列表，点哪个右边直接出它的二维码，“选渠道”和“扫码”合成一页，少点一次“下一步”。右侧内容在剩余区域里居中。改动最大：流程从三页变两页。
