终端横幅：把结对编程、审查一次、先聊再做做成“段”

右半边的手机段已经落地：「状态圆点 + 图标 + 简短状态 + ▾ 下拉」，各段之间用细分隔线隔开。这一页让其余功能也说同一种语言。分两件事：图标和段的排布，两者可以自由组合。 现状的问题有两个：一是图标对不上功能（横幅最左边是“性能分析”图标，右键菜单里“审查一次”在新 UI 下是一个戴帽子的人）； 二是四个蓝色链接一样重，看不出哪个是主要入口，“不再提示”也混在功能入口里。 用上方开关切换图标套组、结对编程状态、是否连着手机。图标套组同时作用于横幅和右键菜单。

一 · 图标套组

点卡片也能切换。平台图标都取自 IDE 2026.2 的新 UI 图标库，未做改动；imux 自绘的三枚以“终端框”为共同母题（imux 的一切都发生在终端会话里），再各加一个记号：第二个终端框、放大镜、问号。三枚都按平台规范画：16×16、1 像素描边、圆角端点、暗色 #CED0D6，另配亮色版。

二 · 方向 A · 一个功能一段推荐

完全照搬手机段的语法：每个功能是一段，段内是「状态图标 + 简短状态 + ▾」，段与段之间是细分隔线。结对编程段把“开启、审查一次、停止、不再提示”都收进下拉菜单，菜单第一行是说明；审查进行中时段内直接给出「取消」，因为它最急。先聊再做只有一个动作，所以不带 ▾，点了就打开；有讨论进行中时前面亮绿点。点「不再提示」后结对段不再消失，只缩成一个图标，随时能找回来。

三 · 方向 B · 左边说状态，右边放功能段

把“发生了什么”和“能做什么”分开：左边整块留给状态句，审查进行中时能完整显示轮次、进度、耗时；所有功能段（结对编程 ▾、先聊再做、手机 ▾）靠右排成一组，像一排工具按钮。空闲时左边是一句淡色提示，告诉新用户这里能做什么。

四 · 方向 C · 图标段，有事才展开

最紧凑：空闲时每个功能段只剩图标（悬停显示名称），横幅几乎是空的；一旦某个功能有状态（结对中、审查中、讨论中、手机在线），对应那段才展开文字和圆点。横幅从“入口列表”变成“状态指示器”。

五 · 右键菜单（随图标套组同步）

终端标签右键菜单里 imux 的几项和横幅用同一套图标，让“横幅上看到的”和“菜单里找到的”能对上。
「连接到手机」沿用已有的手机图标。
右键菜单里本来就有「交接会话」这一项，它不在这次设计范围内，图标保持原样。

三个方向共用的规则：一条横幅；每个功能一段，状态写在段内；「不再提示」只让结对编程段变安静（缩成图标），不会让功能消失；先聊再做的“讨论进行中”状态需要新增一个小接口（查询该会话是否有未关闭的讨论），其余状态都已有数据。
