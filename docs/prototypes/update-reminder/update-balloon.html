新版本提醒 · 气泡模拟

IDE 启动约 30 秒后检查 Marketplace，有兼容的新版本时在右下角弹出标准信息气泡。演示里等待缩短为 1 秒。三个按钮都可以点；把鼠标移到气泡上会出现关闭按钮；不操作的话，气泡约 10 秒后自动收起，收进右侧的通知中心。

去升级在点击所在的窗口打开 Settings → Plugins，由 IDE 下载更新并提示重启；找不到插件页时改用浏览器打开版本页关闭NotificationAction.createExpiring + showSettingsDialog(e.project, id == "preferences.pluginManager")
查看更新内容浏览器打开 plugins.jetbrains.com/plugin/33412-imux/versions保留createSimple + BrowserUtil.browse
忽略此版本记住这个版本号，这个版本不再提醒；发布更新的版本时照常提醒关闭PropertiesComponent 键 imux.update.ignoredVersion

气泡的外观（圆角、阴影、图标、链接样式、自动收起、通知中心）都由 IDE 平台决定，插件只提供标题、内容和三个按钮的文案。用户可以在 Settings → Appearance & Behavior → Notifications 里把 imux.update 组关掉或改成别的展示方式。
