规则

同时多件事

  • 每个来源只保留一条：状态一变，旧提示直接被替换。例如手机断线后，「已连接手机」立刻消失，不会两条并存。
  • 会自动收起的提示要真正显示出来才开始倒数 8 秒：翻页方式下没翻到的那页不计时，鼠标停在条上时全部暂停。
  • 点 × 只收起这一件事；同一件事状态没变就不会再弹出，状态变了（例如又断了一次）会重新出现。

角标（四个图标通用）

  • 无角标：没开启。绿点：开着且正常。黄点：有问题待处理。转圈：正在跑。按下态：对应的面板或窗口开着。
  • 提示条被 × 收起之后，黄点就是唯一的提醒，所以黄点要等问题真正解决了才消失。

浮动图标组

  • 没有角标时半透明；鼠标进入终端上部 80px 或有任何角标时不透明。
  • 拖选终端文字时暂时隐藏。始终停在提示条下方；叠放方式下跟着条数往下移。
  • 第一次打开 Agent 终端时，用 GotIt 气泡指一下图标组，只出现一次。

平台实现与风险

  • 提示条和图标组挂在现有 terminalLayer（JBLayeredPane）上，和「滚到底部」按钮同一层；颜色用 JBUI.CurrentTheme.Banner，角标用 BadgeIconSupplier，图标组用 ActionToolbar + HelpTooltip。
  • 风险：浮动层盖在终端上时，点击和拖选会不会被吃掉，需要做出来在 IDE 里试。
  • 风险：新用户主要靠一次性引导气泡发现入口。
