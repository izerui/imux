# 进展总览 功能设计文档

## 1. 功能定义

**一句话描述**：用户点击"进展总览"后，AI 自动将整个会话的对话内容浓缩为一条按时间顺序排列的关键节点时间线，以弹窗形式展示。

**核心理念**：项目经理视角，不是小兵流水账。用户不需要知道 Agent 读了哪个文件、搜索了什么关键词，只需要看到：目标是什么、怎么判断的、做了什么决策、结果如何——整个开发过程的推进脉络和关键转折。

**解决的问题**：长会话对话记录太多太分散，用户翻聊天记录要半天。几十屏的对话被压缩成一屏可扫完的时间线，让用户快速回顾整个会话干了什么、每步的关键决策是什么。

## 2. 功能入口

### 2.1 会话列表右键菜单

在左侧 AI Agents 面板的会话列表中，右键某个会话，菜单中出现"进展总览"选项：

```
┌──────────────────────────┐
│  重命名                  │
│  复制会话信息            │
│  交接到其他 Agent     ▸  │
│  结对编程             ▸  │
│  ──────────────────────  │
│  进展总览                │  ← 新增
│  ──────────────────────  │
│  删除                    │
└──────────────────────────┘
```

### 2.2 会话正文区域右键菜单

在编辑器标签页中打开的会话正文区域，右键也出现"进展总览"选项，位置与会话列表右键菜单一致。

## 3. 工作流程

### 3.1 主流程

```
用户右键点击"进展总览"
        │
        ▼
┌─────────────────┐
│  检查是否有缓存  │
└─────────────────┘
   │            │
有缓存        无缓存
且无新轮次      或有新轮次
   │            │
   ▼            ▼
直接展示    调用 Agent CLI
缓存内容    生成摘要
(顶部提示    │
 可手动刷新)  ▼
          弹窗展示
```

### 3.2 使用哪个 Agent

跟着会话类型走：
- Claude 会话 → 调用 Claude CLI 生成摘要
- Codex 会话 → 调用 Codex CLI 生成摘要
- Pi 会话 → 调用 Pi CLI 生成摘要

### 3.3 缓存策略

- 记录上次生成摘要时的会话轮次数
- 用户再次点击时，如果轮次数没变化，直接展示缓存的摘要
- 缓存展示时，顶部显示黄色横幅提示"以下为 X 分钟前生成的摘要"，并提供"重新生成"按钮
- 如果会话有新轮次，缓存自动失效，重新生成

### 3.4 超时处理

- 设定超时上限（建议 30 秒）
- 超时后展示失败状态，提供"重新生成"按钮

## 4. 时间线内容

### 4.1 核心原则

- 按**时间顺序**展示整个会话从头到尾的关键节点
- 每个节点**一句话**，不多不少
- AI **自动判断**哪些是关键节点，不固定模板，有几个关键转折就列几个
- **不按轮次拆**，而是按事情推进的逻辑串成一条线
- 中间穿插的无关任务用不同样式区分

### 4.2 主线与穿插任务

一个会话中用户可能中途穿插别的事情（问个无关问题、修个别的 bug 等）。时间线中：

- **主线任务**：用 ● 实心圆标记，正常亮度文字
- **穿插任务**：用 ○ 空心圆标记，灰色弱化文字

AI 摘要时自动识别哪些是主线推进、哪些是穿插。

### 4.3 特殊事件

- **需求方向变更**：用双线框 + ↻ 符号高亮标记
- **尝试后回滚**：用虚线框包围回滚区间，节点改用 ╳
- **执行出错**：用实线框 + ⚠ 警告图标标记
- **正在进行中**：用 ◐ 旋转图标 + "正在：" 前缀

## 5. 节点类型与符号

| 符号 | 含义 | 颜色 |
|:---:|------|------|
| ● | 主线任务节点 | #BBBBBB（正常前景色） |
| ○ | 旁支/穿插任务节点 | #787878（灰色） |
| ╳ | 已回滚/废弃节点 | #8B4513（暗红棕） |
| ↻ | 需求方向变更卡片 | #D4A843（琥珀色） |
| ⚠ | 执行出错卡片 | #C75450（红色） |
| ◐ | 正在进行中 | 旋转动画 |
| │ | 时间线连接线 | #555555（灰色） |

- 右侧出现 IntelliJ 标准细滚动条（6px 宽）
- 滚动时上下边缘有渐隐遮罩（8px 高度的 GradientPaint）提示还有更多内容
- 渐隐规则：
  - 滚动到顶部：无顶部遮罩，有底部遮罩
  - 滚动到中间：顶部 + 底部都有遮罩
  - 滚动到底部：有顶部遮罩，无底部遮罩
  - 内容不足以滚动：无任何遮罩

## 7. 边界情况处理

### 7.1 超长会话（50+ 轮）

对话内容可能超出 Agent CLI 的上下文窗口。处理方式：截取首轮 + 最近 N 轮发送给 Agent，确保不超出上下文限制。

### 7.2 缓存策略

- 记录上次生成摘要时的会话轮次数
- 用户再次点击时，如果轮次数没变化，直接用缓存展示
- 顶部黄色横幅提示"以下为 X 分钟前生成的摘要"+ 可手动"重新生成"
- 会话有新轮次时，缓存自动失效

### 7.3 摘要生成超时

设超时上限（建议 30 秒），超时后展示失败状态（状态 6.9）+ "重新生成"按钮。

### 7.4 摘要质量控制

prompt 中给出示例，约束输出格式和粒度，确保 AI 输出稳定一致。关键约束：
- 每个节点一句话
- 不固定模板，按实际推进逻辑组织
- 自动识别主线与旁支
- 自动识别需求变更、回滚、报错等特殊事件

### 7.5 Agent 正在工作时点击

可以正常点击生成。摘要中最后一个节点用 ◐ 旋转图标 + "正在：" 前缀，表示 Agent 尚未完成当前工作。

### 7.6 弹窗打开后会话继续

弹窗内容是快照，不实时更新。关闭弹窗后，如果会话有新轮次，下次点击会使缓存失效并重新生成。

### 7.7 复制功能

弹窗内文本支持选中复制，方便用户将摘要贴到 PR 描述或发给同事。

### 7.8 同一文件反复修改

摘要只关注最终状态和关键转折，不重复列出每次对同一文件的修改。

### 7.9 改了又全部回滚

最终 diff 为零但过程有意义。摘要应体现"尝试了 X 方案但回退了，原因是 Y"。

## 10. 实现要点

| 设计元素 | 推荐实现方式 |
|---------|------------|
| 弹窗容器 | `JBPopupFactory.createComponentPopupBuilder()` |
| 滚动面板 | `JBScrollPane` + `VERTICAL_SCROLLBAR_AS_NEEDED` |
| 时间线布局 | `JPanel` + `BoxLayout.Y_AXIS` |
| 主题色获取 | `JBColor.namedColor()` |
| 文字截断 | 节点文字最多两行，超出加 `...` |
| 渐隐遮罩 | 覆盖 `paintComponent` 用 `GradientPaint` 绘制 |
| 字体 | `JBUI.Fonts.label(12)` / `JBUI.Fonts.label(13)` |
| HiDPI 适配 | `JBUI.scale(N)` |
| 加载动画 | `AsyncProcessIcon` |
| 关闭方式 | `Esc` 键 / 点击弹窗外部 / 点击 ✕ 按钮 |
