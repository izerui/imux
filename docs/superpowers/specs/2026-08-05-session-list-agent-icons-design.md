# 会话列表 Agent 图标设计

## 目标

在 imux 会话树中增加 Claude 与 Codex 品牌图标，同时完整保留现有的运行中和未读状态标记。

## 展示规则

- Claude Code 分组与会话使用 Claude 品牌图标。
- Codex 分组与会话使用 OpenAI 品牌图标。
- 分组标题只显示品牌图标。
- 已有会话和等待首条消息的新会话始终显示品牌图标。
- 会话状态图标显示在品牌图标右侧：
  - 运行中继续使用 `AllIcons.Nodes.RunnableMark`。
  - 未读继续使用 `AllIcons.General.Modified`。
  - 普通状态使用同尺寸空图标占位，保证标题位置不随状态变化。
- “显示更多”节点不显示 Agent 图标。

## 平台集成

使用 IntelliJ Platform 262 的 `RowIcon` 横向组合品牌图标和状态图标，不自行绘制、缩放或覆盖状态标记。

将现有标签页图标加载逻辑抽取为共享 `AgentIcons`，由 `FileIconProvider` 和会话树共同使用，确保同一 Agent 在不同界面使用同一资源。

## 验证

- 测试共享图标映射仍分别返回 16×16 Claude/Codex 图标。
- 测试组合图标保留两个独立槽位，并在普通状态下保留状态占位。
- 保留现有源码约束测试，确认运行中和未读继续使用平台图标。
- 运行完整测试、插件构建和结构校验。
